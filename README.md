# weekly_digest

Automated weekly research monitor for John Garcia (Associate Professor of Finance, California Lutheran University), tracking new work at the intersection of **large language models as economic/financial agents** and **behavioral finance**.

Each Monday-ish, an agent searches arXiv (q-fin.CP/GN/TR, econ.GN, cs.CL/AI/MA cross-listings), SSRN, NBER, and relevant journals for new work bearing on:

- Garcia's two working papers — "Homo Silicus is Hyper-Rational" (attention-driven trading, disposition effect) and "Algorithmic Anchoring" (prompt-embedded reference points in LLM financial estimates)
- Five planned follow-up studies (anchor retraction/self-anchoring, delegated agents under convex compensation, anchors vs. suitability in robo-advice, instrument-controlled disposition-effect reconciliation, anchor half-life in agent chains)
- Eight open questions in the field (persona bindingness, capability-vs-normative-behavior, affect transfer, framing transfer, sources of hyper-rationality, disposition-effect direction, bubble formation, reproducibility)

Output is a dated markdown file in `digests/`. Verification discipline: every reported paper must carry a resolvable identifier (arXiv ID, DOI, SSRN or NBER number) found directly in a search result or fetched page — no inferring findings from titles alone, and no reporting of details that couldn't be confirmed.
